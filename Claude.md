# Claude.md - Google_4 Project Guidelines

## Project Overview
Google_4 is a game development project featuring Sky Fighter, a Raiden-style vertical shoot-em-up game built with web technologies.

## Project Structure
- `index.html` - Main game application file with embedded HTML, CSS, and JavaScript
- `README.md` - Basic project information
- `.git/` - Git repository configuration

## Technology Stack
- HTML5 Canvas for game rendering
- Vanilla JavaScript for game logic
- CSS3 for styling

## Development Workflow
1. Work on the designated branch: `claude/inspiring-planck-y8algs`
2. Make focused changes with clear commit messages
3. Test changes in a browser before committing
4. Push to the development branch (do not push to main without explicit permission)

## Git Practices
- Write clear, descriptive commit messages
- Include attribution footer on commits: `Co-Authored-By: Claude Haiku 4.5 <noreply@anthropic.com>`
- Test functionality before committing
- Keep commits atomic and focused

## Code Guidelines
- Maintain existing code style and structure
- Avoid unnecessary abstractions
- Document non-obvious logic with brief comments
- Ensure game functionality is tested in-browser

## Key Files to Know
- `index.html` - Contains the complete game application (HTML + CSS + JavaScript)

## Testing
- Test game features by opening `index.html` in a web browser
- Verify game mechanics, rendering, and user interactions
- Check console for errors using browser developer tools

## Common Tasks
- Bug fixes: Locate the issue in `index.html`, fix, test, commit
- New features: Add to `index.html`, test thoroughly, commit
- Performance improvements: Profile in browser, optimize, test, commit
