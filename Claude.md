## Code Structure

The `index.html` file contains:
- **HTML**: Game container and HUD elements
- **CSS**: Styling with responsive design and safe areas for mobile
- **JavaScript**: Complete game logic including:
  - Canvas rendering and animation loop
  - Player ship, weapons, and controls
  - Enemy spawning and behavior
  - Collision detection
  - Game state management
  - Score and statistics

## Development Tips

1. **Canvas Rendering**: The game uses HTML5 Canvas for rendering at 60 FPS
2. **Touch Support**: Implements both touch and keyboard controls for mobile/desktop
3. **Responsive Design**: Game adapts to different screen sizes and safe areas
4. **Dark Theme**: Uses a space/sky blue color scheme

## Performance Considerations

- Minimize object allocation in the game loop
- Use object pooling for bullets and effects if needed
- Profile rendering performance on target devices
- Optimize collision detection algorithms
