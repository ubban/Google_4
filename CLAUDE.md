# Sky Fighter — Codebase Documentation

## Project Overview

**Sky Fighter** is a Raiden-style vertical shoot-'em-up game built with vanilla HTML5, CSS, and JavaScript. The game runs entirely in a single-file HTML document with no external dependencies.

### Key Features
- Vertical scrolling shoot-'em-up gameplay
- Weapon switching mechanics
- Smart bomb drops
- Stage bosses
- Mobile and desktop support
- Responsive canvas rendering

## Key Implementation Details

### Architecture

The entire game is contained within a single `index.html` file organized as:
- **HTML Head**: Meta tags, viewport configuration, embedded styles
- **HTML Body**: Canvas element and HUD container
- **Embedded JavaScript**: Game loop, input handling, collision detection, rendering

### Game Loop

The game uses `requestAnimationFrame` for smooth 60 FPS rendering:
- Input processing (keyboard, mouse, touch)
- Game state updates
- Collision detection
- Rendering to canvas

### Input Handling

- **Keyboard**: Arrow keys or WASD for movement
- **Mouse**: Position-based targeting and clicking for actions
- **Touch**: Mobile-friendly touch input support

### Core Game Systems

1. **Player Ship**: Main character controlled by the player
2. **Weapons System**: Multiple weapon types with switching
3. **Enemy Spawning**: Wave-based enemy generation
4. **Collision Detection**: Hit detection for bullets, enemies, and player
5. **Boss Encounters**: Stage-based boss fights
6. **Scoring System**: Points and combo tracking
7. **HUD**: Health, ammo, score, and stats display
