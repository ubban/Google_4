# Sky Fighter - Claude Code Guidelines

## Project Overview

**Sky Fighter** is a Raiden-style vertical shoot-em-up game built with HTML5 Canvas and vanilla JavaScript. The game features:
- Player-controlled fighter jet with weapon switching
- Smart bomb mechanics
- Stage bosses with distinct attack patterns
- Responsive touch and mouse controls
- Dynamic UI with HUD elements (health, ammo, stage info)

## Development Guidelines

### Code Organization

The game is implemented as a single HTML file (`index.html`) containing:
- **HTML Structure**: Single canvas container for game rendering
- **CSS Styling**: Responsive game UI with viewport handling and safe areas
- **JavaScript Game Logic**: Canvas API-based rendering, game state management, entity systems

### Key Game Systems

When working on the game, focus on these core systems:

1. **Game Loop**: Canvas rendering, frame rate management, delta time calculations
2. **Entity System**: Player, enemies, projectiles, bosses, effects
3. **Input Handling**: Mouse and touch input for aiming and firing
4. **Collision Detection**: Hit testing for weapons, enemies, and bosses
5. **UI/HUD**: Score, health, ammo display, stage information
6. **Audio**: Sound effects and background music (if applicable)

### Code Style

- **No external dependencies**: Game uses vanilla JavaScript and HTML5 Canvas only
- **Single file architecture**: Keep logic contained within index.html
- **Comments**: Add comments for complex game mechanics, collision logic, and state transitions
- **Variables**: Use descriptive names for game entities and state variables

### Testing Guidelines

- Test gameplay in different browsers (Chrome, Firefox, Safari, Edge)
- Verify responsive behavior on various screen sizes and devices
- Test touch controls on mobile devices
- Check performance on low-end devices (monitor FPS)

## Common Tasks

### Adding/Modifying Game Features

- **New Enemy Type**: Add entity class and update spawning logic in game loop
- **New Weapon**: Define weapon parameters and update player firing logic
- **UI Changes**: Modify HUD rendering and canvas positioning

### Bug Fixes

- Test reproduction case first
- Identify system affected (collision, input, rendering, etc.)
- Make minimal, focused changes
- Verify fix doesn't break other features

### Performance Optimization

- Profile with browser DevTools before optimizing
- Focus on game loop, rendering, and collision detection
